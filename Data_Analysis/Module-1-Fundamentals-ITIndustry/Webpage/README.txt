# Dhiren Gohel — Data Analytics Portfolio

## Files
- index.html — complete responsive portfolio webpage
- avatar.png — avatar asset used by the page

## Run
Open `index.html` directly in a browser.

## Customize
Search `index.html` for:
- `your.email@example.com`
- `+91 XXXXX XXXXX`
- `linkedin.com/in/your-profile`
- `github.com/your-username`
- project links (`href="#"`)
- CV filename/link

The contact form currently opens the visitor's email client using `mailto:`.
For a production contact form, connect it to your preferred form/backend service.
